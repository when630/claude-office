# 설정

상단바 오른쪽 **설정** 버튼. 고른 값은 `%APPDATA%\claude-office\settings.json`
(맥은 `~/Library/Application Support/claude-office/settings.json`)의 `view`에 남아
앱을 다시 켜도 그대로다.

## 클로드 이름

이름표에 무엇을 쓸지 고른다. 세션 이름은 작업 디렉터리나 첫 지시에서 나오므로
화면을 남에게 보일 때 가려야 할 수 있다.

| 값 | 이름표 | 패널 제목 |
|---|---|---|
| 이름 그대로 | `claude-office` | `claude-office` |
| 가리기 | `클로드 1` | `클로드 1` |
| 이름표 없음 | (없음) | `클로드 1` |

- 대체 이름은 **스냅샷 순서대로 붙인 번호**다. 캔버스와 패널이 같은 이름을 부르므로 누구를 눌렀는지는
  그대로 알 수 있다. 이름표를 없앤 경우에도 패널 제목은 대체 이름으로 남는다 — 제목이 비면
  무엇을 열었는지 알 수 없다
- 이름을 숨겨도 **컨텍스트 게이지는 남는다.** 그건 이름표가 아니라 상태 표시이고, 자리 높이도
  이름이 있을 때와 같게 유지해 방 크기가 흔들리지 않는다
- 회의실 **명패는 접어 눕힌다** — 빈 카드를 세워두면 명패가 고장 난 것처럼 보인다
  (자리를 비웠을 때와 같은 모습)
- 가려지는 건 **이름표뿐이다.** 방 이름(작업 디렉터리)과 패널의 `cwd`는 그대로 남는다

## 방 종류

지금 떠 있는 방마다 `자동`(해시 배정) + 8종 중에서 고른다. 손으로 고른 종류는 자동
배정보다 먼저 못 박고 "이미 쓴 종류"로 세므로, 남은 방들이 그 종류를 피해 간다. 기억하는 열쇠는
**작업 디렉터리 이름**이라 방이 사라졌다 다시 떠도 고른 종류가 붙어 있다.

`renderer/themes.mjs`에 종류를 하나 추가하면 이 목록에도 자동으로 뜬다.
